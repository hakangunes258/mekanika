# YouTube Channel Setup - Phase 1 Checklist

## Week 1: Channel Setup & Branding (Estimated: 3-4 hours)

### Day 1-2: Channel Creation & Configuration ⏰ 1 hour

#### Step 1: Create YouTube Channel
- [ ] Go to youtube.com and sign in with youtube@mekanika.org
- [ ] Click on profile icon → "Create a channel"
- [ ] Choose "Use a custom name" → Enter "Mekanika"
- [ ] Confirm creation

#### Step 2: Basic Settings
- [ ] Go to YouTube Studio → Settings
- [ ] **Channel → Basic info:**
  - [ ] Paste channel description from `channel-setup.md`
  - [ ] Add keywords: mechanical engineering, calculator, engineering tools
  - [ ] Set country: United States
- [ ] **Channel → Advanced settings:**
  - [ ] Category: Science & Technology
  - [ ] Enable: "Set as made for kids" → NO
  - [ ] Enable: Comments → Allow all comments
- [ ] **Upload defaults:**
  - [ ] Default visibility: Public
  - [ ] Category: Science & Technology
  - [ ] License: Standard YouTube License
  - [ ] Tags: (paste from channel-setup.md)

#### Step 3: Channel Sections
- [ ] Go to YouTube Studio → Customization → Layout
- [ ] Enable "Customize the layout of your channel"
- [ ] Create sections:
  - [ ] Section 1: "Getting Started" (Featured content)
  - [ ] Section 2: "Shaft-Hub Connections" (Playlist)
  - [ ] Section 3: "Fasteners" (Playlist)
  - [ ] Section 4: "Bearings" (Playlist)
  - [ ] Section 5: "Springs" (Playlist)

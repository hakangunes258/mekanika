## 8. Export Settings

### For YouTube Upload (Best Quality):

**Video:**
- Container: MP4
- Codec: H.264
- Resolution: 1920×1080 (1080p)
- Frame Rate: 30 FPS
- Bitrate: 8-12 Mbps (VBR)
- Color Space: Rec. 709

**Audio:**
- Codec: AAC
- Sample Rate: 48 kHz
- Bitrate: 192-320 kbps
- Channels: Stereo (2.0)

**Thumbnails:**
- Format: JPG (smaller file size)
- Quality: 90% (balance between size and quality)
- Color Profile: sRGB

## 9. Accessibility Guidelines

### Color Contrast:
- Text on blue background: Use white (#ffffff)
- Minimum contrast ratio: 4.5:1 (WCAG AA)
- Test tool: https://webaim.org/resources/contrastchecker/

### Text Readability:
- Minimum font size: 36pt for thumbnails
- Minimum font size: 24pt for videos
- Avoid script/cursive fonts
- Use bold weights for emphasis

### Captions/Subtitles:
- Enable YouTube auto-captions
- Review and edit for technical terminology
- Upload corrected .srt file if needed
